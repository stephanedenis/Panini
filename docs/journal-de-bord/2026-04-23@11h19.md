## Résumé des décisions

### 1. H2 v3 — Phrases définitionnelles (résolution du cluster dense)

**Problème §73** : H2 v2 donnait ρ=0.019 sur mots isolés. Diagnostic : les mots philosophiques abstraits (« temps », « mesure », « intégration ») forment un cluster dense dans l'espace sentence-transformer (cos ≈ 0.629 partout), rendant toute corrélation impossible.

**Solution v3** : Remplacer les mots isolés par des **phrases définitionnelles en 5 langues** qui encodent explicitement les atomes constitutifs de chaque molécule. Exemple :  
> « Le temps est l'articulation de la différence, du rapport et de l'orientation : le temps est la différence ordonnée entre des moments, structurée en rapport avec une direction. »

**Résultats** :
- ρ = **0.472** (p = 3.7e-7) — hautement significatif
- Δρ = **+0.453** vs H2 v2
- cos_moy = 0.415 (vs 0.629 en v2) — la variance augmente, le cluster se brise
- Distribution cohérente : Jaccard≈0 → cos=0.325, Jaccard≈0.5 → cos=0.479, Jaccard≈0.75 → cos=0.470
- Fichier : `research/nipada/falsification/H2_v3_phrases_definitionnelles.json`

**Verdict** : AMBIGU (signal partiel) mais signal réel et robuste statistiquement. La structure atomique nipada est **détectable** quand les phrases encodent explicitement les atomes — ce qui confirme que le problème de H2 v2 était l'opérationnalisation (mots isolés), non la structure nipada elle-même.

**Interprétation** : Le modèle sentence-transformer encode les relations sémantiques **explicites** dans le texte, pas la structure compositionnelle latente. Pour détecter la structure nipada, il faut que les définitions la rendent visible. C'est une contrainte méthodologique importante pour toute validation ultérieure.

### 3. H3 v2 — Recalibration des poids ℂ*

**Contexte** : H3 v1 avait comparé cos(COLÈRE, FEU) = 0.466 au poids théorique subjectif 0.30 (verdict AMBIGU, δ=0.166).

**H3 v2** : Test de calibration empirique sur 8 paires nipada connues.

**Résultat surprenant** : sur la matrice mots-isolés, la calibration donne **ρ=-0.365** (pente **négative** : slope=-0.443, intercept=0.881). Interprétation : le même artefact cluster-dense que H2 v2 — les concepts structurellement proches (fort Jaccard) ont des cosinus *plus bas* car ils appartiennent tous au même cluster philosophique dense.

**Conclusion H3 v2** :
- Sur mots isolés : cos(INTENTION, TRANSFORMATION) = 0.472 → **poids recalibré empirique = 0.472** (vs 0.30 initial)
- La calibration Jaccard→cosinus est **inversée** sur mots isolés (cluster dense)
- Pour une calibration correcte, il faudra utiliser la matrice phrases-définitionnelles (H2 v3)
- **Le poids 0.30 est remplacé par 0.472** dans le modèle ℂ* pour la paire (INTENTION, TRANSFORMATION)
