## Contexte général — le projet Panini

**Panini** (projet parent, GitHub : stephanedenis/Panini) est un système d'extraction
de primitives sémantiques appliqué aux formats de fichiers binaires (PaniniFS). Son
hypothèse fondatrice : les structures de formats courants (PNG, JPEG, ZIP, MP4, PDF…)
s'organisent selon un petit nombre de **primitives conceptuelles universelles** — les
*dhātu* de la grammaire de Pāṇini (IVe siècle av. J.-C.).

Pāṇini lui-même avait identifié dans l'Ashtādhyāyī les *dhātu* comme les racines
irréductibles de la langue sanskrite : ~2000 racines dont ~40 sont fondamentales.
Le projet Panini transpose cette intuition à la couche informatique.

## Session du 7 septembre 2025 — La découverte des 9 dhātu optimaux

**Commit de référence** : `RESUME_SESSION_RECHERCHE_20250907.md`

**Question de départ** (formulée par Stéphane Denis) :
> "Continuons les recherches sur les découvertes. Le but est d'augmenter les atomes
> sémantiques au besoin tout en visant à être capable de représenter le sens complet
> de tout texte à l'aide d'un minimum d'atomes définis."

### Résultat : 9 dhātu optimaux

Par optimisation combinatoire (`dhatu_set_optimizer.py`, 1000+ combinaisons testées) :

| Dhātu | Racine skt | Sens | Origine |
|-------|-----------|------|---------|
| RELATE | √bandh | Relier, connecter | Original |
| MODAL | √śak | Modalité, possibilité | **Nouveau** |
| EXIST | √as | Exister, être présent | **Nouveau** |
| EVAL | √man | Évaluer qualitativement | **Nouveau** |
| COMM | √vac | Communiquer, échanger | Original |
| CAUSE | √nī | Causer, provoquer | **Nouveau** |
| ITER | √vṛt | Répéter, parcourir | Original |
| DECIDE | √cit | Choisir, décider | Original |
| FEEL | √spṛś | Sentir, percevoir | Original (renommé) |

**Couverture sémantique** : 66.7% → 71.7% (+5%) avec point de rendements décroissants
à 9 dhātu (10e dhātu : Δ=0%). Ces 9 dhātu deviendront plus tard la base de V9.

### Analyse concurrentielle — territoire vierge confirmé

Domaines analysés lors de cette session :
- **NSM (Wierzbicka)** : 65 primitives linguistiques. Plus large que nos 9 dhātu,
  non-computable (Nirenburg), instabilité cross-linguistique (Levinson)
- **Semantic Deduplication** (Abbas 2023) : hash sémantique, sans primitives universelles
- **Universal Grammar** (Baker, Goddard, Pereira) : syntaxe universelle, pas sémantique
- **Sémantique computationnelle** (Jackendoff, Pustejovsky) : framesets, événements

**Conclusion** : aucune approche combinant primitives sanskrites + optimisation combinatoire
+ systèmes informatiques. Fenêtre de priorité estimée à 6-12 mois.

## Session du 19 septembre 2025 — Révolution géométrique

**Fichier** : `JOURNAL_SESSION_GEOMETRIE_DHATU_20250919.md`  
**Commit** : `30916a2` — *RÉVOLUTION GÉOMÉTRIQUE DHĀTU : Modélisation spatiale relations + GPU RX 480*

**Découverte** : les dhātu peuvent être modélisés comme des **objets géométriques
dans un espace vectoriel 9D**. La distance cosinus entre vecteurs-dhātu mesure les
relations structurelles (inclusion, exclusion, égalité).

```
EXIST ⊆ RELATE : distance cosinus = 0.248  (inclusion confirmée)
COMM ⊆ EVAL    : distance cosinus = 0.108  (inclusion forte)
DECIDE ⊆ EVAL  : distance cosinus = 0.052  (quasi-identité cognitive)
EXIST ∩ FLOW = ∅ : distance = 0.762        (exclusion)
```

**Conséquence** : la signature d'un texte = projection dans l'espace 9D. La distance
entre deux textes est calculable en O(n) avec GPU (5.83 TFLOPS RX 480 = 69 168 textes/sec,
×12 vs CPU).

Cette session pose la fondation empirique qui, combinée au graphe documenté de
transmission philosophique, donnera la formulation de H₀ :

> *La distance lexicale V14 est proportionnelle à la distance topologique dans le
> graphe de transmission philosophique documenté.*

## 22 avril 2026 — Pivot théorique : Leibniz + Spencer-Brown → V14

**Fichier** : `docs/journal-de-bord/2026-04-22.md` (première entrée du journal officiel)

Ce jour est le **pivot fondateur de NIPADa**. La session reconstruit l'architecture
théorique depuis ses fondements.

### La voie leibnizienne

**Leibniz (1679)** : *Characteristica Universalis* + *Alphabetum Cogitationum Humanarum*.  
Méthode : assigner chaque primitive à un **nombre premier**. Les concepts composés
sont le **produit** de leurs primitives.

```
BOUNDARY=2, SEQUENCE=3, VALUE=5, REFERENCE=7, REPETITION=11…
PNG header = BOUNDARY × SEQUENCE × VALUE × TYPE = 2×3×5×19 = 570
```

Avantages :
- Vérifier si un concept contient une primitive = divisibilité O(1)
- Ajouter une primitive ne casse pas les encodages existants
- GCD de deux concepts = intersection sémantique

**Connexion Gödel** : Gödel (1931) a utilisé cette technique pour encoder les formules
syntaxiques — la numérotation de Gödel. L'incomplétude implique que toute encyclopédie
suffisamment riche contiendra des concepts indécidables. Pour NIPADa : une feature,
pas un bug.

### Le triangle irréductible (Spencer-Brown)

Gregory Bateson : *"The elementary unit of information is a difference that makes
a difference."*

George Spencer-Brown (*Laws of Form*, 1969) : toute la logique dérive d'une seule
opération — **tracer une distinction**.

```
ÊTRE ←→ DIFFÉRENCE ←→ RAPPORT
```

Ces trois aspects sont mutuellement nécessaires. C'est le nœud d'interdépendance :
on ne peut pas réduire davantage sans perdre la possibilité même de décrire quoi
que ce soit. Les 3 premiers nombres premiers du système leibnizien nipada.

### V14 — l'architecture finale des primitives

À partir de ce pivot, les 9 dhātu (V9) sont réorganisés et étendus en **V14** :

```
ÊTRE=2, DIFFÉRENCE=3, RAPPORT=5, ORIENTATION=7, SUJET=11, TEMPS=13,
MODALITÉ=17, NOMBRE=19, ESPACE=23, OPÉRATION=29, FONCTION=31,
STRUCTURE=37, SYMÉTRIE=41, ÉQUATION=43
```

14 primitives, 14 nombres premiers. Couverture sémantique supérieure à NSM (65
primitives linguistiques non-computables) avec une base mathématiquement fondée.

**Le lien Łukasiewicz / Zadeh** :
- Łukasiewicz (1920) : logique trivaluée → les primitives peuvent avoir des degrés
  d'appartenance (vrai / faux / indéterminé), pas seulement présence/absence
- Zadeh (1965) : logique floue → les signatures V14 sont des vecteurs réels normalisés,
  pas des vecteurs binaires. Chaque texte a un degré d'appartenance à chaque atome

**Filiation complète** :

```
Pāṇini (IVe s. av. J.-C.)         — dhātu irréductibles de la langue
    ↓
Leibniz (1679)                     — Characteristica Universalis + Gödel numbers
    ↓
Łukasiewicz (1920) / Zadeh (1965)  — logique trivaluée + floue
    ↓
Wierzbicka (1972) / Mel'čuk (1996) — primitives sémantiques + fonctions lexicales
    ↓
Spencer-Brown (1969)               — triangle irréductible ÊTRE/DIFFÉRENCE/RAPPORT
    ↓
NIPADa V14 (avr. 2026)            — 14 atomes, signatures vectorielles, H₀ falsifiable
```
