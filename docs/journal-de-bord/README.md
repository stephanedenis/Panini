## Structure d'un journal

Chaque journal suit la structure :

```markdown
# Journal de bord — YYYY-MM-DD

## Contexte
(État au début de la session)

## Plan journée complète — ~N étapes
(Plan numéroté par blocs §)

## Sessions du jour
(Comptes-rendus en temps réel)
```

## Conventions de nommage

- Un fichier par jour calendaire (même si plusieurs sessions)
- Nom : `YYYY-MM-DD.md`
- Sections référencées : `§NNN` (numéro de section du roadmap)
