### 2. H2 v2 — test cosinus cohérence

**Problème avec H2 v1 (PCA)** : trop naïf. Chercher une correspondance PC ↔ atome
dans une PCA 8-composantes sur 15 points n'a pas de pouvoir statistique.

**Nouvelle approche** : pour chaque paire (A, B) de molécules,
- `predicted = Jaccard(atomes_A, atomes_B)`
- `observed  = cosine(embed_A, embed_B)`

Spearman sur les 105 paires.

**Résultats H2 v2** :
```
ρ = 0.019 (p = 0.85)
mean_cosine_observé = 0.629 (±0.13)
predicted_range : [0.00, 0.75]
observed_range  : [0.34, 0.94]
```

Paires par bucket Jaccard :
| Jaccard prédit | n pairs | cosinus moyen |
|---------------|---------|--------------|
| ≈ 0.00 | 25 | 0.627 |
| ≈ 0.25 | 40 | 0.619 |
| ≈ 0.50 | 24 | 0.666 |
| ≈ 0.75 | 16 | 0.605 |

**Diagnostic** : Les cosinus observés ne varient pas avec le Jaccard prédit. Tous les concepts
abstraits ("être", "mesure", "temps", "tout"...) se retrouvent dans un cluster dense de
l'espace sémantique — les similarités cosinus sont uniformément ≈ 0.63 quelle que soit
la distance structurelle nipada.

**Interprétation** : Ce résultat ne falsifie pas la **structure nipada** — il falsifie
l'**opérationalisation** (mot isolé → vecteur). Les mots abstraits philosophiques
sont comprimés dans une région dense de l'espace sentence-transformer.

**Cause** : sentence-transformers entraînés sur des paires de phrases — les mots abstraits
("time", "whole", "measure") apparaissent dans des contextes syntaxiques similaires
et sont encodés voisins indépendamment de leur structure sémantique profonde.
