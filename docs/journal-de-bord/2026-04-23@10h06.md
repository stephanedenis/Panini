### Décisions prises

**1. Format JSON exclusif pour v1.0**

Le format JSON est choisi comme format primaire de l'encyclopédie nipada. Les formats binaires et l'extension OntoWave pour la navigation seront développés ultérieurement, en s'appuyant sur cette fondation JSON stable.

Justification : JSON est lisible, versionnable, et suffisamment structuré pour une extension de navigation future. Le schéma canonique est défini dans `schema.json`.

**2. Découverte de l'encodage 4 bits (session précédente)**

Insight fondamental cristallisé en début de session : les 15 molécules canoniques sont exactement isomorphes à un encodage 4 bits avec `0b0000` comme padding :

```
bit0 = ÊTRE (2)
bit1 = DIFFÉRENCE (3)
bit2 = RAPPORT (5)
bit3 = ORIENTATION (7)
```

- `0b0000` = 0 → padding (produit vide = 1, avant toute distinction)
- `0b1111` = 15 → INTÉGRATION (nipada value = 210)
- `popcount(mask)` = `level` — invariant fondamental

Ce champ `mask` a été ajouté à tous les fichiers JSON existants.

**3. Périmètre v1.0 : 32 entrées confirmées**

| Domaine | Nb | Contenu |
|---------|-----|---------|
| Z+ (positif) | 15 | 4 atomes + 6 mol. binaires + 4 mol. ternaires + 1 quaternaire |
| Z- (crossings) | 15 | Spencer-Brown crossing de chaque molécule positive |
| iZ (imaginaire) | 2 | MOI (70i) + TRACE (15i) |
| **Total v1.0** | **32** | **Complet et vérifiable sans hypothèses** |

### Raisonnements importants

**Pourquoi les crossings sont dérivés mécaniquement mais nécessitent un travail philosophique :**

Le crossing `-n` n'est pas une simple négation logique. Spencer-Brown définit le crossing comme la traversée d'une frontière. Pour chaque molécule, son crossing traverse la frontière fondatrice qui définit cette molécule. Cela requiert d'identifier quelle frontière est franchie et quel concept émerge de l'autre côté.

Exemple : `-21` = crossing OPPOSITION. La frontière traversée est la directionnalité du conflit. De l'autre côté : la différence subsiste mais sans orientation combattante = PAIX. Ce n'est pas "pas d'opposition" (ce serait une négation logique) mais "traversée de la frontière directionnelle de l'opposition".

**Pourquoi 15i = TRACE (et non un autre concept) :**

MESURE = DIFFÉRENCE × RAPPORT = différence mise en relation = quantité. Son auto-référence (×i) = la mesure qui se mesure elle-même = le paradoxe du mètre-étalon de Paris (Wittgenstein : il ne peut pas se mesurer lui-même). La trace est exactement ce concept : elle "mesure" une présence passée en n'étant plus là elle-même. C'est une mesure auto-efforçante, une présence-absence simultanée — impossible en Z, native en iZ.
