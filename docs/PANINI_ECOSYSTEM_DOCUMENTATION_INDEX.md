### Core Concepts Explained
- **Atomic Decomposition**: Breaking files into reusable atoms (explained in Orientation Package)
- **FUSE3**: Virtual filesystem in userspace (explained in Orientation Package)
- **Dhātu**: Sanskrit semantic primitives (explained in Orientation Package)
- **CAS**: Content-Addressed Storage (explained in Orientation Package)
- **Orchestrator Pattern**: Unified multi-backend execution (explained in Master Doc)
- **MCP**: Model Context Protocol for AI tools (explained in Orientation Package)
- **Handoff Pattern**: Context transfer between AIs (explained in Orientation Package)
